# 기능 카드 (예시 주제)

기능 백로그가 비었을 때 `/next`가 여기서 후보를 고릅니다. 크기는 요구사항을 읽었을 때의 짐작일 뿐, 실제로 얼마나 바뀌는지는 팀의 설계에 따라 다릅니다.

## 인스타그램

| 크기 | 기능 |
| --- | --- |
| 작은 | 게시물에 장소 이름을 붙일 수 있다 |
| 작은 | 사용자는 프로필 사진을 가진다 |
| 중간 | 게시물 하나에 사진을 여러 장 올린다. 사진에는 순서가 있다 |
| 중간 | 댓글에 답글을 단다. 답글에는 다시 답글을 달지 않는다 |
| 큰 | 사용자는 다른 사용자를 팔로우한다. 내가 팔로우한 사람의 게시물만 모아 본다 |
| 큰 | 게시물을 지워도 그 게시물의 댓글 수와 좋아요 수 기록은 남긴다 |

## 도서관 대출

| 크기 | 기능 |
| --- | --- |
| 작은 | 책에 출판사 이름을 남긴다 |
| 작은 | 대출마다 반납 예정일을 남긴다 |
| 중간 | 책 하나가 분류 여러 개에 속할 수 있다 (소설이면서 역사) |
| 중간 | 같은 책이 여러 권 있다. 회원은 그중 한 권을 빌린다 |
| 큰 | 빌려 간 책을 다른 회원이 예약하고, 예약한 순서대로 빌린다 |
| 큰 | 반납 예정일보다 늦게 돌려주면 연체 일수를 남기고, 연체 중인 회원은 빌릴 수 없다 |

## 배달 앱

| 크기 | 기능 |
| --- | --- |
| 작은 | 가게에 영업 시작 시각과 끝 시각을 남긴다 |
| 작은 | 손님은 배달 요청사항을 주문마다 적는다 |
| 중간 | 손님은 배달 주소를 여러 개 저장하고, 주문할 때 하나를 고른다 |
| 중간 | 가게가 분류 여러 개에 속할 수 있다 (치킨이면서 피자) |
| 큰 | 메뉴 가격이 바뀌어도 지난 주문의 금액은 그대로 남아야 한다 |
| 큰 | 메뉴에 옵션(곱빼기 +1,000원 · 치즈 추가 +500원)을 고를 수 있고, 주문한 메뉴마다 옵션을 여러 개 고른다 |
