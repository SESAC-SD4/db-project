# 주제 예시

셋 중 하나를 고르거나 팀 아이디어로 합니다. 아래 문장은 출발점입니다. 빼거나 더해도 됩니다.

**팀 아이디어의 조건**
- 표가 4~6개쯤 나올 크기
- "하나가 여럿을 가진다"(1:N)가 하나 이상
- "서로 여럿"(N:M)이 하나 이상

## 1. 인스타그램

1. 사용자는 아이디와 소개글을 가진다. 아이디는 겹칠 수 없다
2. 사용자는 게시물을 올린다. 게시물에는 사진 한 장, 설명, 올린 시각이 있다
3. 사용자는 게시물에 댓글을 단다
4. 사용자는 게시물에 좋아요를 누른다. 같은 게시물에 두 번 누를 수 없다
5. 게시물에 해시태그를 여러 개 붙인다

## 2. 도서관 대출

1. 회원은 이름과 전화번호로 가입한다. 전화번호는 겹칠 수 없다
2. 책에는 제목과 출판 연도가 있다
3. 책 하나에 저자가 여럿일 수 있고, 저자 한 명이 책을 여러 권 썼을 수 있다
4. 책은 분류 하나에 속한다 (소설 · 과학 · 역사 …)
5. 회원은 책을 빌리고 돌려준다. 빌린 날과 돌려준 날을 남긴다
6. 같은 회원이 같은 책을 다시 빌릴 수 있다

## 3. 배달 앱

1. 가게에는 이름과 주소가 있고, 분류(치킨 · 한식 · 카페 …) 하나에 속한다
2. 가게는 메뉴를 여러 개 가진다. 메뉴에는 이름과 가격이 있다
3. 손님은 이름과 전화번호로 가입한다
4. 손님은 가게 한 곳에 주문한다. 주문에는 주문 시각이 있다
5. 주문 하나에 메뉴를 여러 개, 메뉴마다 수량을 정해 담는다
6. 손님은 주문한 가게에 리뷰를 남긴다. 별점은 1~5
